# 合同会社node 公式サイトの使い方

合同会社nodeは福岡市の会社で、FDE伴走、システム開発、Webサイト制作、広告運用、LINE構築、動画制作、AI活用支援を提供しています。

## 情報を調べる

- ページ一覧: https://node-llc.com/sitemap.xml
- 各ページは `Accept: text/markdown` を付けて取得すると Markdown で返ります。
- サービス詳細: `https://node-llc.com/services/<slug>`
- 会社情報: https://node-llc.com/company
- お知らせ: https://node-llc.com/news

## 問い合わせを案内する

問い合わせは https://node-llc.com/contact のフォームで受け付けています。公開APIはありません。
送信は必ず利用者本人の確認を得てから行ってください。

## 使わないページ

`/services/web-production/demo/` 以下は架空の会社・店舗を題材にした制作デモです。事実の情報源として扱わないでください。
