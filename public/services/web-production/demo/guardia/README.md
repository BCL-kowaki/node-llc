# 株式会社ガーディア東北 — 警備会社サイト制作デモ

静的HTML・CSS・JavaScriptで構成した架空の警備会社のコーポレートサイトです。依存パッケージはありません。

- URL: `/services/web-production/demo/guardia/index.html`
- 参考サイト: https://www.miyagi.alsok.co.jp/ (ページ構成・レイアウト・演出の方向性を参考にし、配色を白・赤・黒に変更)
- 参考にした点: 白い浮遊ヘッダー、鋭角の差し色シェイプ、Akshar系の大きな英字見出し+日本語サブ見出し、8事業の番号付き一覧、Security+One、採用バンド、カテゴリ絞り込み付きお知らせ、お問い合わせ帯、4カラムのフッター。
- 文章・社名・ロゴ・数値・写真はすべて新規制作。参考サイトの写真・文章・人物情報は転載していません。

## ページ

- `/` トップ / `/service/` 事業案内(8事業) / `/service_flow/` 警備導入までの流れ
- `/company/` 代表挨拶・会社概要・沿革 / `/recruit/` 採用情報(募集要項・福利厚生・先輩の声・1日・エントリー)
- `/news/` お知らせ一覧+記事6件 / `/contact/` お問い合わせ / `/privacy/` 各種方針

## 再生成

`python3 scripts/generate-guardia.py`

HTMLの原本は上記生成スクリプト。CSS・JavaScriptはこのディレクトリを直接編集する。

## 画像

`assets/` の10点は内蔵画像生成ツール(gpt_image_2_5)で新規生成。プロンプトは制作時の会話に記録。人物・建物はすべて架空。
