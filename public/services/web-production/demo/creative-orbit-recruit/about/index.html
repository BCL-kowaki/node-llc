About us.

戦略とクリエイティブで、新しい軌道を。

そのブランドに、
次の可能性を。

いい商品やサービスが、必要とする人にまだ届いていない。私たちは、その距離を縮めるために生まれたクリエイティブカンパニーです。

戦略づくりからWeb制作、広告、日々の改善まで。数字と感性の両方を大切にしながら、クライアントと一緒に事業の成長を目指します。

「こうすれば、もっと良くなる」。その気づきを、肩書きや経験に関係なく持ち寄れるチームでありたいと考えています。

Our values.

VALUE 01

Stay curious.

問いを楽しもう。

当たり前をそのままにしない。小さな違和感に目を向け、新しい視点を見つける。

VALUE 02

Create together.

違いを力にしよう。

専門も経験も異なる仲間の意見を聞く。対話の先に、一人では出せない答えがある。

VALUE 03

Keep moving.

まず、一歩進めよう。

考え抜いたら、小さく試す。結果から学び、より良い次の一手につなげる。
